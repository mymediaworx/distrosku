# Michael's roadmap, 2026-10-21 (verbatim intent; supersedes earlier "no settlement" decision)
## Tier 1 (before go-live)
1. Hemp/THC gating: per-SKU total THC/container, synthetic-cannabinoid flag, COA upload, rule engine blocking sales by effective date + state, inventory-at-risk report (federal cutoff moved Nov 12 -> Dec 11 2026).
2. Cigarette tax stamps module (admin toggle; Vega OFF by default): stamp purchase/inventory/affixing, reconciliation to stock, "stamped for state X" on stock blocking cross-state sale.
3. Sales tax + exemption certs: resale/exemption cert capture w/ expiry, tax-exempt flags per customer & ship-to, tax on invoices. Excise effective-dated, versioned rate tables snapshotted onto each filing.
4. Product eligibility registry: MSA, FDA vape marketing-authorization status per SKU, state vape directories (confirm KY), flavor bans, local rules.
5. Cash handling: till open/close, drops, over/short, Z-report, driver cash settlement w/ deposit slips, NSF returned-check workflow, cumulative cash per customer for IRS 8300 (>$10k).
6. Quick-tools link: require named login or PIN, log activity, new SKUs pending manager approval, tax class locked to approvers, duplicate-UPC detection.
## Tier 2
Order-to-cash: POS/van supervisor PIN credit override w/ reason + hold sale; batch invoicing, auto-invoice on delivery, month-end delivered-uninvoiced check; multi-invoice payment application, unapplied cash, prepayments/deposits; auto credit hold by aging, late fees; quotes, backorders, standing orders, cutoffs, delivery minimums/fees; Rep tools module (default OFF): commissions, mobile/offline order entry, visit notes.
Purchasing: vendor EDI/electronic PO send; vendor invoice import; landed cost allocation; vendor returns/stale credits; PO approval thresholds; manufacturer scan-data/trade programs (Altria STARS).
Warehouse/delivery: tiered count tolerances + reason codes + adjustments-by-user report (clarify or/and); mobile/remote short-pick approval; refused-stop alert + default credit memo/cancel path; Row/Shelf location on all products; wave/zone picking + carrier rate shopping (later).
Accounting: document costing method + inventory valuation-to-GL rec; 1099 tracking; CPA/QuickBooks export; pre-close checklist blocking close.
## Tier 3
Audit export package (KY DOR/ATF) w/ retention + legal hold; customer license lifecycle (expiry alerts, auto-block, docs, eligibility matrix by license type; supplier licenses); price floors (counsel: KY cigarette minimum markup); open API + webhooks; ops hygiene (tested backups, uptime, sign-in rate limit, Rules Hub change approval); customer features (price-change notices, new-item alerts, portal buying history & rebates).
